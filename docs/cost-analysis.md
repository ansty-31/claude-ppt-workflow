## 详细成本分解

### 方案 1：全程 Claude 生成可编辑 PPTX

#### 工作流
```
Claude 阅读需求 → 生成 python-pptx 代码 → 迭代调试 → 验收
```

#### Token 消耗明细（22 页 PPT）

| 阶段 | 输入 | 输出 | 总计 | 备注 |
|-----|------|------|------|------|
| 需求理解 | 15K | 5K | 20K | 读需求文档、参考资料 |
| 代码生成 | 20K | 60K | 80K | 4 个 slides_*.py 文件 |
| 图表调试 | 25K | 25K | 50K | 坐标偏移、字体映射 |
| 布局微调 | 15K | 10K | 25K | 修孤字、重叠、溢出 |
| 验收审计 | 10K | 5K | 15K | lines.py + imgcheck |
| 返工（1–2 轮） | 20K | 20K | 40K | 设计变更、数据更新 |
| **首次生成** | **105K** | **125K** | **230K** | **≈ $3.5** |
| **后续修改（单次）** | **15K** | **10K** | **25K** | **≈ $0.4** |

#### 真实案例（SEA-Loop）
- **首次生成**：~150K tokens ≈ $2.5（比预期省，因复用了部分模板）
- **G2 改版尝试**：~243K tokens ≈ $3.5（失败，浪费 ~$2.0 在崩溃和返工上）
- **前期学习成本**：~1.4M tokens ≈ $23.5（探索 python-pptx API、字体渲染等）
- **总计**：~$30（今日）+ $20（前期）= **$50**

#### 成本驱动因素
1. **学习曲线**：首次使用 python-pptx 时，探索 API 的成本占 70%
2. **大文件陷阱**：读 1.3MB SVG → 崩溃 → 返工，浪费 ~$2
3. **子代理协调**：并行 3 个 builder 的通信成本 ~$0.5
4. **重复渲染**：每次迭代都跑 `soffice → pdftoppm`，浪费 5–10 分钟

#### 优化空间
如果有现成模板和工具脚本：
- 首次生成：~60K tokens ≈ **$1.0**
- 后续修改：~15K tokens ≈ **$0.25**

### 方案 2：三阶段混合（推荐）

#### 工作流
```
Claude Opus 生成大纲 → Jinja2 模板化生成 PPTX → DALL-E 3 精修视觉
```

#### Token 消耗明细

| 阶段 | 输入 | 输出 | 总计 | 美元成本 |
|-----|------|------|------|---------|
| **阶段 1：内容生成** | | | | |
| 大纲生成（Opus） | 3K | 5K | 8K | $0.12 |
| **阶段 2：布局与数据** | | | | |
| 模板化生成 | 0 | 0 | 0 | $0（纯代码） |
| 微调辅助（Sonnet） | 10K | 10K | 20K | $0.18 |
| **阶段 3：视觉精修** | | | | |
| DALL-E 3 生图 | N/A | N/A | N/A | $0.64（16 页 × $0.04） |
| **总计** | **13K** | **15K** | **28K** | **$0.94** |

#### 后续修改成本
- 改数据/文字：改 YAML → 重新运行 Jinja2 → $0
- 改布局：调用 Claude 微调 → ~5K tokens ≈ $0.08
- 重新生图：DALL-E 3 → $0.04/页

#### 优势
- **成本稳定**：不受"学习成本"影响（模板可复用）
- **质量可控**：DALL-E 3 的字体渲染优于 python-pptx
- **增量更新**：只需重新生成改动页

#### 劣势
- **不完全可编辑**：最终 PNG 不可编辑（但阶段 2 的 PPTX 可作为"源文件"）
- **依赖外部 API**：DALL-E 3 有 rate limit（50 请求/分钟）

### 方案 3：纯人工 + 设计师

#### 工作流
```
需求沟通 → 设计师出稿 → 反馈修改 → 定稿
```

#### 成本明细
- 初级设计师（淘宝/Fiverr）：$50–100
- 中级设计师（国内工作室）：$150–250
- 高级设计师（4A 广告公司）：$500–2000

#### 时间成本
- 初稿：1–2 天
- 修改（2 轮）：2–3 天
- **总计**：3–5 天

#### 适用场景
- 品牌发布会（需要完美视觉）
- 融资路演（投资人评审）
- 客户提案（商务拓展）

#### 不适用场景
- 内部技术汇报（性价比低）
- 数据驱动的季度报告（频繁更新）
- 教学课件（批量生成）

## 成本优化建议

### 1. 预处理大文件（省 $2–5）
```bash
# 5 分钟人工 → 省 2 小时返工
python3 extract_coords.py design.svg > coords.txt
```

### 2. 模板化生成（省 50–70% token）
```python
# ❌ 逐页调用 Claude
for page in pages:
    claude(f"生成第 {page} 页的 python-pptx 代码")

# ✓ 一次性生成模板，数据驱动
template = claude("生成 PPT 模板代码，用 {{变量}} 占位")
for data in datasets:
    exec(template.format(**data))
```

### 3. 增量验证（省 30% 渲染时间）
```bash
# ❌ 每次改动都渲染完整 PDF
改代码 → soffice → pdftoppm → lines.py

# ✓ 语法检查 → 最终一次渲染
改代码 → py_compile → (循环) → 最终渲染
```

### 4. 本地 SD 替代 DALL-E（省 75% 生图成本）
```bash
# DALL-E 3: $0.04/图 × 20 页 = $0.80
# Stable Diffusion XL 本地: ~$0.01/图 × 20 = $0.20
# 节省：$0.60/次，20 次后节省 $12（GPU 成本回本）
```

## 总结

### 最优方案选择

| 如果你... | 推荐方案 | 预期成本 |
|---------|---------|---------|
| 首次尝试，预算紧张 | 方案 2（混合） | $1–2 |
| 需要频繁修改数据 | 方案 1（Claude） | $3–5（首次）+ $0.3/次 |
| 批量生成（>10 份） | 方案 2 + 模板 | $1（首次）+ $0.1/份 |
| 极致视觉要求 | 方案 3（人工） | $150–300 |

### 成本控制关键

1. **减少试错**：预处理大文件，明确任务拆解
2. **复用模板**：第一次投入高，后续边际成本趋近于 0
3. **选对工具**：技术内容用 Claude，视觉呈现用生图模型
4. **增量迭代**：不要一次性"完美"，先 MVP 再优化

### 投资建议

- **个人/小团队**：投入 $50–100 建立工具链，3–5 个项目后回本
- **企业/机构**：投入 $500–1000 开发企业模板库，批量生成边际成本 <$0.5/份
- **一次性需求**：用 Canva / Gamma.ai（$10–20），不值得学习 python-pptx

---

**最后提醒**：成本不仅是美元，还包括时间、学习曲线和试错风险。选择方案时，综合考虑 TCO（Total Cost of Ownership）而非单次直接成本。
